# Plugin Development Guide
created: 2026-09-15
aliases: plugin development, plugin development guide

The Plugin Development Guide defines the standard for all new gaon plugins: TypeScript, Node 20+, MCP over stdio, dist/index.js entry, and Plugin Meta.
New plugins should not use Python as the default stack. Structure includes src/index.ts, config.ts, server.ts, and tools modules.

Rules: stderr only for logs, validate config at startup, stable tool names, write operations default off, never put secrets in git.
After coding, build, install or rsync to plugins volume, enable via Control Plane, run Sync Lifecycle, then verify loadReport.
