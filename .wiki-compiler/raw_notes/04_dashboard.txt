# Dashboard
created: 2026-09-15
aliases: Admin UI, admin dashboard

Dashboard is the React admin UI under packages/dashboard, typically port 5173 in dev.
Operators use it to install git or npm plugins, enable them, view status, and trigger management actions against Control Plane.

It does not serve MCP traffic. All MCP sessions go through Core SSE endpoints.
After install or enable changes, Sync Lifecycle must run so Core enabled list matches the registry.

Related: Control Plane, Install Worker, Core, Plugin Development Guide.
