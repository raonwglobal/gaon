# External MCP Plugins
created: 2026-09-15
aliases: external plugins, third-party MCP

External MCP Plugins are full MCP servers installed from git or npm rather than in-repo McpPlugin classes.
Node external plugins use node dist/index.js. Python ones need python3 in the Core image and a project-local .venv because of PEP 668.

Plugins volume may be read-only; create venv on the host when the mount is ro.
Operational guide: docs/external-mcp-plugins.md.
Related: Stdio Bridge, Plugin Meta, Install Worker, Core, Plugin Development Guide.
