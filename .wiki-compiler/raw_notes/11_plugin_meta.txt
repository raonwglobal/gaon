# Plugin Meta
created: 2026-09-15
aliases: plugin.meta.json, ExternalPluginMeta

Plugin Meta is a JSON file at the root of each installed plugin directory.
Required fields for stdio plugins: id, runtime=stdio, command, args. Optional: env, envFromHost, description, version.

Secrets must not be committed in Plugin Meta. Prefer Control Plane config or host environment variables listed in envFromHost.
Install Worker generates Plugin Meta after npm build or Python venv preparation when possible.

Related: Stdio Bridge, Install Worker, Plugin Development Guide, External MCP Plugins.

Discovery rebuilds factories after Install Worker updates the plugins directory.
