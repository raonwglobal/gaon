# Plugin Runtime
created: 2026-09-15
aliases: plugin-runtime, Runtime Catalog

Plugin Runtime supports modes such as inprocess and container or endpoint orchestration.
Inprocess mode loads factories discovered from PLUGINS_DIR and built-in plugins like weather and echo.
Container mode can route tools to remote runtimes described in the Runtime Catalog.

Mode is selected with PLUGIN_RUNTIME and ORCHESTRATOR environment variables.
Most production external plugins today use inprocess plus Stdio Bridge rather than full container isolation.

Related: Core, Stdio Bridge, Plugin Manager, Docker Compose.
